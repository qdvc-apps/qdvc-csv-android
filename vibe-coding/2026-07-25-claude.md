**What's implemented**
- **Table grid** with the first row as **sticky column headers** — the header stays pinned while the body scrolls vertically, and both share one horizontal scroll so columns stay aligned. Includes a row-number gutter and zebra striping.
- **"Open with" support** — `MainActivity` is exported with `VIEW` intent filters matching CSV MIME types plus a `.csv` extension pattern (for when the file browser reports a generic MIME type). Also handles `SEND`.
- **Settings page** — Light / Dark / System selector, defaulting to **System** so it follows your OS. Persisted via DataStore.
- **namespace / applicationId** = `qdvc.csv.android.app`.
- A dependency-free CSV parser handling quoted fields, embedded commas/newlines, escaped quotes, CRLF/LF, BOM, and delimiter auto-detection. Parsing runs off the main thread.

Build with `./gradlew assembleDebug` or open in Android Studio. Note: I couldn't run a full Gradle build here (Android SDK isn't available in this environment), but the parser's edge cases are unit-verified and the project structure is standard.
